## Kısa Özet

- IMU kart üzerinde SPI ile gelir.
- Motor ve enkoder akışı GPIO ile sürülür.
- Ultrasonik sensörler yine GPIO ile okunur.
- Lidar USB seri üzerinden bağlanır.
- Kamera CSI üzerinden bağlanır.
