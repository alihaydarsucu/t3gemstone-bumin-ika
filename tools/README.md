# Araçlar

Bu klasör build, flash, test ve log toplama yardımcıları için ayrılmıştır.
Henüz script eklenmedi.

- log toplama (`/diagnostics` ve node log'larını tek yerde toplama)
- flash script (kart imajı yazma yardımcısı)
